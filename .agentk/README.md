# `.agentk/` — Agent K project root

설정과 에이전트 관련 정보는 **여기만** 둡니다. (`.agent-k/` 는 쓰지 마세요.)

| Path | Purpose |
|------|---------|
| `settings.json` | 프로젝트 설정 (provider, permissions, features, …) |
| `plans/` | Plan mode 문서 / tmp drafts |
| `debug/` | Debug mode 세션 |
| `checkpoints/` | 롤백 체크포인트 |

새 파일·폴더도 모두 `.agentk/` 아래에 추가하세요.
